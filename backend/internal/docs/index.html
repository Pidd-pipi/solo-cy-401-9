自由职业者撮合平台 · API 文档

Go 1.22 + Gin + GORM · /docs/openapi.json

认证

POST/api/v1/auth/register注册（requester/freelancer/both）
POST/api/v1/auth/login登录（requester01/freelancer01/demo123456）
GET/api/v1/auth/me当前用户

需求 Requirement

GET/api/v1/requirements需求大厅（status/minBudget/maxBudget/skill/page/page_size）
POST/api/v1/requirements发布需求
GET/api/v1/requirements/:id需求详情（含报价）
PUT/api/v1/requirements/:id编辑需求
POST/api/v1/requirements/:id/status状态流转
POST/api/v1/requirements/:id/accept-bid采纳报价并生成合同

报价 Bid

GET/api/v1/bids?requirementId=报价列表
POST/api/v1/bids提交报价
POST/api/v1/bids/:id/withdraw撤回报价

合同 Contract

GET/api/v1/contracts我的合同
GET/api/v1/contracts/:id合同详情（含阶段）
POST/api/v1/contracts/:id/sign签署确认
POST/api/v1/contracts/:id/complete完成确认

其它

GET/api/v1/dashboard我的工作台

PATCH/api/v1/users/:id编辑资料
GET/api/v1/operation-logs操作日志
